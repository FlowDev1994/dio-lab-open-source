# 🌐 Minha Contribuição em um Projeto Open Source (Lab DIO)

### 📄 Sumário do Projeto
Este repositório documenta minha participação no laboratório **"Contribuindo em um Projeto Open Source no GitHub"**, oferecido pela [Digital Innovation One (DIO)](https://www.dio.me/). O objetivo principal foi simular um fluxo de trabalho completo de contribuição em um projeto de código aberto, desde o fork até o pull request.

<br>

▶️ **Veja a comunidade:** [**Acesse a página do projeto aqui**](https://flowdev1994.github.io/dio-lab-open-source/)

---

### 🎯 O Objetivo do Laboratório

O desafio consistia em adicionar um perfil pessoal à galeria da comunidade do projeto. Para isso, segui os seguintes passos:
1.  **Fork:** Criei uma cópia (fork) do repositório principal para minha conta pessoal.
2.  **Branch:** Criei uma nova branch para isolar minha contribuição.
3.  **Contribuição:** Adicionei um arquivo Markdown com minhas informações na pasta `community`.
4.  **Pull Request:** Abri um Pull Request para o repositório original, que foi revisado e aceito (merged), integrando minha contribuição ao projeto principal.

### 💡 Aprendizados e Habilidades Desenvolvidas

A conclusão deste laboratório solidificou minhas habilidades no fluxo de trabalho padrão do mercado para colaboração em projetos de software:

* **Git & GitHub Flow:** Compreensão prática de como criar forks, branches, commits e pull requests.
* **Colaboração em Equipe:** Entendimento de como propor alterações em um código base que não é seu, seguindo as diretrizes de contribuição.
* **Markdown:** Utilização da linguagem de marcação para criar e formatar documentos de forma limpa.
* **Cultura Open Source:** Vivência do processo colaborativo que move a comunidade de código aberto.
